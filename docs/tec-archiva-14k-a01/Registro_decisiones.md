# Registro de decisiones · 14K

| Decisión | Estado | Evidencia requerida |
|---|---|---|
| Identidad y disponibilidad del custodio | Pendiente | Confirmación del responsable y canal autorizado |
| Acceso administrativo histórico | PENDING_CUSTODIAN | Ingreso autorizado, rol y consulta permitida, con conformidad del custodio |
| Arranque para validar, si se requiere | NOT_GRANTED | Autorización específica con IDs, servicios, ventana y alcance |
| Política del destino | PENDING_APPROVAL | Decisión del responsable, huellas revisadas, condiciones y fecha |
| Actualización local | NOT_GRANTED | Aprobación expresa independiente y cierre del checklist de 14J |
| Permiso para el original | Cero emitidos | Aprobación específica posterior para la operación, si procede |
| Decisión de cambio | NO_GO | Cierre documentado de los pendientes y respaldo al corte verificado en la ventana |

Los campos pendientes reflejan ausencia de evidencia. Adjuntar las decisiones recibidas con nombre, rol, fecha y referencia de origen.
