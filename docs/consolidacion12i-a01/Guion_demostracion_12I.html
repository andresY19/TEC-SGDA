Guion de demostración GEOLOGY 12I

Versión del guion 12D para la candidata consolidada. Ejecución con usuarios y documentos sintéticos. Aceptación institucional pendiente.

Usar las cuentas sintéticas de la campaña, con credenciales entregadas por el operador fuera de la proyección. Mostrar el resultado de las pruebas que escriben datos mediante sus evidencias.

Pantalla o endpoint

Perfil

Resultado esperado
Ingreso válido y restricciones correctas y tokens nunca en URL.
Evidencia
Evidencias de ejecución 12I en la matriz de este paquete.
